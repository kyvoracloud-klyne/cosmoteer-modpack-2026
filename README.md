# Cosmoteer Mod Pack 2026

Version 1.0.15 is the current GitHub release. The files in this repository are not the mods.

`manifest.json` names pack `modpack-2026` and archive `modpack-2026-1.0.15.zip`, split into `.000`–`.002` parts. Releases also attach `files-1.0.15.json` and `delta-1.0.14-to-1.0.15.zip` for launcher 1.0.4+ delta upgrades.

Version 1.0.15 adds six Workshop ship-design collections (Stargate SGC/Wraith/Goa'uld/Asgard fleets, EuroSpace All-In-One-Bundle 2, War Above All Heavens). Stargate A.W.T is not included.
