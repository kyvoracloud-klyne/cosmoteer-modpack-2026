# Cosmoteer Mod Pack 2026

Version 1.0.8 is the current GitHub release. The files in this repository are not the mods.

`manifest.json` names pack `modpack-2026` and archive `modpack-2026-1.0.8.zip`, split into `.000`–`.002` parts. Releases also attach `files-1.0.8.json` and `delta-1.0.7-to-1.0.8.zip` for launcher 1.0.4+ delta upgrades.

Version 1.0.8 restores Cable Age remote power to 512 tiles (so Huge Ship shields get wireless power again) while keeping the ModPack Performance network-port overlay OOM guard. Stargate A.W.T is not included.
