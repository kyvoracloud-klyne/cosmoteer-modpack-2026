# Cosmoteer Mod Pack 2026

Version 1.0.0 is a GitHub release. The files in this repository are not the mods.

`manifest.json` names pack `modpack-2026` and archive `modpack-2026-1.0.0.zip`. GitHub release files cannot exceed 2 GB, so that zip is uploaded as ordered parts:

- `modpack-2026-1.0.0.zip.000`
- `modpack-2026-1.0.0.zip.001`
- `modpack-2026-1.0.0.zip.002`

The mod pack launcher downloads the parts in that order and joins them back into the zip. Stargate A.W.T is not in version 1.

Newer versions are newer releases of this repository with their own `manifest.json`.
