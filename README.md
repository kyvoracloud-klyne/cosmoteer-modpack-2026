# Cosmoteer Mod Pack 2026

Version 1.0.11 is the current GitHub release. The files in this repository are not the mods.

`manifest.json` names pack `modpack-2026` and archive `modpack-2026-1.0.11.zip`, split into `.000`–`.002` parts. Releases also attach `files-1.0.11.json` and `delta-1.0.10-to-1.0.11.zip` for launcher 1.0.4+ delta upgrades.

Version 1.0.11 ships ModPack Performance 1.0.3 (skip network-port overlay on blueprints with 2000+ parts; tighter BFS queue/time budget) and Cable Age’s 5×-batched SW reactor wireless links. Stargate A.W.T is not included.
