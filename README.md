# Cosmoteer Mod Pack 2026

Version 1.0.7 is the current GitHub release. The files in this repository are not the mods.

`manifest.json` names pack `modpack-2026` and archive `modpack-2026-1.0.7.zip`. GitHub release files cannot exceed 2 GB, so that zip is uploaded as ordered parts:

- `modpack-2026-1.0.7.zip.000`
- `modpack-2026-1.0.7.zip.001`
- `modpack-2026-1.0.7.zip.002`

Releases also attach `files-1.0.7.json` and `delta-1.0.6-to-1.0.7.zip`. Launcher 1.0.4+ applies a matching delta when an older pack version is already cached.

Version 1.0.7 stops the ship-designer network-port overlay OutOfMemory crash on hover by capping long-range grid buffs (Cable Age remote power at 128 tiles) and guarding the overlay in ModPack Performance 1.0.1. Stargate A.W.T is not included.

Newer versions are newer releases of this repository with their own `manifest.json`.
