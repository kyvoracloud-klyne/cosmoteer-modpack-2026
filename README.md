# Cosmoteer Mod Pack 2026

Version 1.0.14 is the current GitHub release. The files in this repository are not the mods.

`manifest.json` names pack `modpack-2026` and archive `modpack-2026-1.0.14.zip`, split into `.000`–`.002` parts. Releases also attach `files-1.0.14.json` and `delta-1.0.13-to-1.0.14.zip` for launcher 1.0.4+ delta upgrades.

Version 1.0.14 caps dedicated point-defense and flak range at 350 m and multiplies Bigger Deck Guns shell Health by 5×. Stargate A.W.T is not included.
