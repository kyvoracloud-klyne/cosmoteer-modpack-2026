# Cosmoteer Mod Pack 2026

Version 1.0.5 is the current GitHub release. The files in this repository are not the mods.

`manifest.json` names pack `modpack-2026` and archive `modpack-2026-1.0.5.zip`. GitHub release files cannot exceed 2 GB, so that zip is uploaded as ordered parts:

- `modpack-2026-1.0.5.zip.000`
- `modpack-2026-1.0.5.zip.001`
- `modpack-2026-1.0.5.zip.002`

The mod pack launcher downloads the parts in that order and joins them back into the zip. Version 1.0.5 widens Cable Age Remote Power for Huge Ships and updates Halo reactor and shield rules. Stargate A.W.T is not included.

Newer versions are newer releases of this repository with their own `manifest.json`.
