# Cosmoteer Mod Pack 2026

Version 1.0.10 is the current GitHub release. The files in this repository are not the mods.

`manifest.json` names pack `modpack-2026` and archive `modpack-2026-1.0.10.zip`, split into `.000`–`.002` parts. Releases also attach `files-1.0.10.json` and `delta-1.0.9-to-1.0.10.zip` for launcher 1.0.4+ delta upgrades.

Version 1.0.10 ships ModPack Performance 1.0.2 with a fail-fast network-port overlay guard so large heat-pipe and power networks cannot freeze or OOM the designer on hover. Stargate A.W.T is not included.
