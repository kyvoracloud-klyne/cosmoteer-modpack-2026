# Cosmoteer Mod Pack 2026

Version 1.0.16 is the current GitHub release. The files in this repository are not the mods.

`manifest.json` names pack `modpack-2026` and archive `modpack-2026-1.0.16.zip`, split into `.000`–`.002` parts. Releases also attach `files-1.0.16.json` and `delta-1.0.15-to-1.0.16.zip` for launcher 1.0.4+ delta upgrades.

Version 1.0.16 hotfixes unique builtin ship IDs for the Workshop ship collections added in 1.0.15 (fixes Duplicate built-in ship ID 'Sentry'). Stargate A.W.T is not included.
