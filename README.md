# Cosmoteer Mod Pack 2026

Version 1.0.17 is the current GitHub release. The files in this repository are not the mods.

`manifest.json` names pack `modpack-2026` and archive `modpack-2026-1.0.17.zip`, split into `.000`–`.002` parts. Releases also attach `files-1.0.17.json` and `delta-1.0.16-to-1.0.17.zip` for launcher 1.0.4+ delta upgrades.

Version 1.0.17 lets the Galactic Allegiance missile silo fire base-game high-explosive, EMP, and thermal missiles, and mines. Nuclear missiles stay off this silo. Stargate A.W.T is not included.
